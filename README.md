# Coding Lessons

A step-by-step course in Python and software engineering, from first principles to production-quality code.

- The full plan is in [docs/lesson-plan.md](docs/lesson-plan.md).
- Each lesson is a folder in [lessons/](lessons/). Start with [Lesson 0](lessons/00-your-workspace/README.md).
- [pocket_ledger/](pocket_ledger/) is the capstone project, an expense tracker that grows a little with every lesson.

## How each lesson works

1. Read the lesson's `README.md`.
2. Fill in the lesson's exercise file, `lesson_NN.py` (for example `lesson_00.py`).
3. Check your work by running the tests from the top of the repository:

   ```
   python lessons/00-your-workspace/test_lesson_00.py
   ```

   (Use `python3` instead of `python` if that is what your computer has.)
4. Do the capstone step described at the end of the lesson, then commit.

Stuck for 20 minutes? Ask. Paste what you tried and the error message.
